# 🤖 Голосовой помощник Кеша

**Кеша** — это голосовой ассистент с графическим интерфейсом، написанный на Python. Он умеет распознавать речь، выполнять команды، отвечать голосом، управлять компьютером и искать информацию в интернете. Проект создан для автоматизации повседневных задач и может быть легко расширен.

---

## 🚀 Возможности

- 🎤 **Голосовое управление** — распознавание команд через микрофон ((Google Speech Recognition)).
- 🔊 **Синтез речи** — озвучивание ответов с помощью `gTTS`.
- 🖥️ **Управление компьютером**:
  - открытие/закрытие приложений ((по названию или ярлыкам на рабочем столе));
  - регулировка громкости системы;
  - блокировка، выключение، перезагрузка، спящий режим;
  - скриншоты، управление мышью и клавиатурой.
- 🌐 **Поиск в интернете** — поиск в Яндексе، YouTube، открытие сайтов.
- 🎵 **Музыка** — поиск и воспроизведение треков через Яндекс.Музыку ((открытие в браузере)).
- 🎮 **Игры** — запуск встроенных игр ((камень-ножницы-бумага، виселица، викторина، квест، крестики-нолики، угадай число)).
- 🧠 **Умный ответ** — при нераспознанной команде используется **GigaChat** ((если установлен модуль `gig`)).
- 📚 **Учёба** — быстрый доступ к электронному дневнику، оценкам، расписанию ((МЭШ)).
- 🏠 **Умный дом** — управление светом через Алису ((Яндекс)).
- 🎨 **Красивый интерфейс** — графический интерфейс на Pygame с отображением статуса، диалогов и списка команд.

---

## 📦 Требования

- Python **3.10** и выше
- Микрофон и динамики
- Установленные библиотеки ((см. `requirements.txt`))

---

## ⚙️ Установка

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/ваш-username/kesha.git
   cd kesha
   ```

2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

   Если файла `requirements.txt` нет، установите вручную:
   ```bash
   pip install pygame speechrecognition gtts keyboard mouse psutil requests beautifulsoup4 youtube-search AppOpener
   ```

3. ((Опционально)) Для работы с GigaChat создайте файл `gig.py` с функцией `ask_gigachat((prompt))`, которая возвращает ответ.

4. Запустите:
   ```bash
   python Kesha.py
   ```

---

## 🎮 Использование

1. **Активация** — произнесите одно из ключевых слов: *«Кеша»*, *«Кеш»*, *«Гоша»*, *«Чебурек»*, *«Алиса»*, *«Кэш»*.
2. После активации скажите команду. Например: *«Кеша، открой браузер»*.
3. Кеша выполнит команду и озвучит ответ.
4. Интерфейс показывает статус، последнюю команду и диалог.

## 📋 Список команд

### 🎯 Основные
- `привет` — поздороваться
- `как дела` — узнать состояние
- `молодец` — похвалить Кешу
- `пока` / `выход` — завершить работу

### 🌐 Интернет и поиск
- `найди [запрос]` — поиск в Яндексе
- `найди в ютуби [запрос]` — поиск видео на YouTube
- `youtube` — открыть YouTube
- `игры` — открыть Яндекс Игры
- `погода` — текущая погода
- `переводчик` — открыть переводчик
- `дипси` — открыть DeepSeek

### 🎮 Игры
- `камень ножницы бумага`
- `виселица`
- `викторина`
- `квест`
- `крестики-нолики`
- `угадай число`

### 💻 Система и приложения
- `открой [приложение]` — например، `открой браузер`, `открой вс код`
- `закрой [приложение]`
- `открой проводник` / `открой настройки`
- `сверни окно` / `закрой окно`
- `камера` / `селфи`
- `левый клик` / `правый клик`

### 🎵 Медиа и управление
- `музыка [название]` — поиск трека
- `моя волна` / `избранное`
- `стоп` / `пауза`
- `дальше` / `следующий`
- `предыдущий` / `прошлый`
- `лайк` / `дизлайк`
- `громче` / `тише` / `громкость [0-100]`

### ⚙️ Системная информация
- `время` — текущее время
- `батарея` — состояние батареи
- `выключи компьютер`
- `перезагрузка`
- `спящий режим`
- `заблокируй компьютер`

### 📚 Учёба
- `дз` / `домашнее задание` — открыть ДЗ в МЭШ
- `оценки` — открыть оценки
- `расписание` — расписание на завтра

### 🔧 Специальные
- `переведи на английский [текст]`
- `переведи на русский [текст]`
- `нарисуй [запрос]` — поиск картинок
- `включи свет` / `выключи свет` — через Алису
- `вниз` / `верх` — скролл
- `поставь таймер на [минуты]`
- `телефон` — открыть звонки
- `bluetooth` — переключить Bluetooth

## 🧩 Дополнительно

- **GigaChat**: если установлен модуль `gig.py`, Кеша может отвечать на неизвестные команды с помощью GigaChat.

- **Интеграция с роботом**: при желании можно адаптировать для управления роботом ((например، Yahboom)).
