# 🤖 Кеша Бот - Telegram ассистент для управления компьютером

![Python](https://img.shields.io/badge/Python-3.8+-blue?logo=python)
![Telegram](https://img.shields.io/badge/Telegram-Bot-2CA5E0?logo=telegram)
![License](https://img.shields.io/badge/License-MIT-green)

**Кеша Бот** — это мощный Telegram бот, который превращает ваш мессенджер в пульт дистанционного управления компьютером. Управляйте системой, ищите информацию в интернете, играйте в игры и многое другое прямо из Telegram!

## ✨ Основные возможности

### 🖥️ **Управление компьютером**
*   **Мышь**: перемещение курсора, клики (левые, правые, средние), скроллинг.
*   **Клавиатура**: нажатие клавиш, отправка текста, горячие клавиши (`Win + D`, `Alt + F4` и др.).
*   **Система**: выключение, перезагрузка, спящий режим, блокировка, информация о батарее.
*   **Приложения**: открытие и закрытие любых программ (через `AppOpener`).
*   **Громкость**: увеличение/уменьшение, установка точного уровня.
*   **Управление окнами**: свернуть, закрыть, открыть проводник, настройки.
*   **Bluetooth**: быстрое переключение режима.

### 🌐 **Интернет и поиск**
*   Поиск в Яндексе и на YouTube.
*   Открытие YouTube, Яндекс Игр, Яндекс Музыки.
*   Погода в вашем городе.
*   Быстрый доступ к нейросети DeepSeek и переводчику.

### 🎮 **Игры и развлечения**
*   Запуск встроенных игр: "Камень, ножницы, бумага", "Виселица", "Викторина", "Квест", "Крестики-нолики", "Угадай число".

### 🎵 **Управление медиа**
*   Поиск и воспроизведение музыки (Яндекс.Музыка).
*   Управление треками: пауза/стоп, следующий/предыдущий, лайк/дизлайк.

### 📚 **Помощь в учебе**
*   Быстрый доступ к электронному дневнику (МЭШ): домашние задания, оценки, расписание.

### 🔧 **Специальные команды**
*   Таймер обратного отсчета.
*   Создание аудиофайла из текста (TTS).
*   "Умный дом" — управление светом через Алису.
*   Интеграция с GigaChat для ответов на сложные вопросы.

## 🛠️ Установка и запуск

### Требования
*   Python 3.8 или выше.
*   Компьютер с Windows (для полного функционала управления).
*   Telegram Bot Token (получите у [@BotFather](https://t.me/botfather)).

### Шаги по установке

1.  **Клонируйте репозиторий:**
    ```bash
    git clone https://github.com/Naruto456y/kesha.git
    cd kesha
    ```

2.  **Установите необходимые библиотеки:**
    ```bash
    pip install -r requirements.txt
    ```
    *(Если файла `requirements.txt` нет, создайте его со списком зависимостей: `python-telegram-bot`, `psutil`, `requests`, `keyboard`, `mouse`, `youtube-search-python`, `pycaw`, `comtypes`, `AppOpener`, `gtts`)*

3.  **Настройте токен:**
    *   Откройте файл `KeshaBot_fa.py`.
    *   Найдите строку `TOKEN = "YOUR_TELEGRAM_TOKEN"` и замените старый токен на ваш собственный.
    *   *Рекомендация:* для безопасности храните токен в отдельном файле (например, `Token_fa.txt`) и читайте его оттуда.

4.  **Запустите бота:**
    ```bash
    python KeshaBot_fa.py
    ```

## 🎯 Использование

1.  Найдите своего бота в Telegram и отправьте команду `/start`, чтобы увидеть список всех доступных команд.
2.  Просто пишите боту текстовые запросы на русском языке, например: "Кеша, открой браузер", "найди в ютубе смешные котики", "какая погода?", "поставь таймер на 5 минут".
